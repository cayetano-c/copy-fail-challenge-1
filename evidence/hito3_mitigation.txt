Nota: En sistema real rmmod algif_aead bloquea el exploit.

Explicacion:
La forma de mitigar el bug desde el punto de vista del kernel pasa por descargar el módulo algif_aead del kernel usando rmmod algif_aead. Este módulo es el que expone la interfaz AF_ALG al espacio de usuario para las operaciones AEAD (Authenticated Encryption with Associated Data). Si no se realiza esta operación, el exploit no puede crear el socket AF_ALG necesario para hacer que se active el bug.
Si se quiere que esta mitigación persista entre reinicios, se debe insertar install algif_aead /bin/false en /etc/modprobe.d/disable-algif.conf, lo que hará que el kernel rechace cualquier intento de cargar el módulo automáticamente.
El trade-off es que las aplicaciones que usen cifrado autenticado a través de AF_ALG (algunas implementaciones de IPSec, WireGuard o algunas herramientas criptográficas que usen directamente la interfaz del kernel) dejarán de funcionar.
